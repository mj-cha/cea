# CEA 교육·컨설팅 홈페이지 에이전트 분업 큐 (WORK-QUEUE)

> **규칙 원본**: `AGENTS.md`(7대 설계 기준·15KB 파일 상한·단일 UI 스택), `CLAUDE.md`(교차 검증 의무).
> **핵심 주의**: **유료 구독 클로드(총괄 CTO)**와 **터미널 클로드 코드(`freellmapi` 로컬 에이전트)**는 계정과 세션을 공유하지 않는 **별개의 직원**입니다. 모든 인계와 검수는 대화창 기억이 아니라 이 파일(`docs/WORK-QUEUE.md`)과 Git 커밋 기록을 기준으로만 진행합니다.

## 2. 작업 및 교차 검증 절차 (4단계)

1. **지시서 등록 및 1차 검수 (`freellmapi` 터미널 클로드)**:
   - 유료 구독 클로드(CTO)의 기획이나 새 작업 요청을 받으면, 코드를 짜기 전에 **5줄 이내 텍스트 설계안**과 **[범위 / 하지 말 것 / 완료 조건]**을 먼저 정리합니다.
2. **자동 교차 검증 첨부 (필수)**:
   - 아래 명령을 실행해 정량 감사 + Codex CLI 의견을 지시서 하단에 첨부합니다(FAIL 0건 확인 전에는 구현 착수 금지):
     `node C:/Users/aweth/.agents/scripts/cto-audit.mjs --dir . --codex --timeout-ms 60000`
3. **전담 구역 분업 구현**:
   - 각 에이전트는 위 표의 자기 전담 파일만 수정합니다(파일당 **15KB 상한** 엄수, 타 UI 라이브러리 추가 금지).
4. **빌드·검증 및 1작업 = 1커밋**:
   - `npm run build` 오류 0 + `npm run audit:cto` FAIL 0 확인 후 `dev` 브랜치에 커밋합니다.
